v31 installer workflow and UI update

- Detect an existing ProjectDB installation and show Install or Update mode explicitly.
- Present ProjectDB Service Manager v31, ProjectDB 3.4.0 and Windows x64 package information.
- List WinSW 2.12.0 x64 as an installed MIT-licensed third-party component and install THIRD-PARTY-NOTICES.txt.
- Add installation-directory selection for new installations, defaulting to C:\Program Files\ProjectDB.
- Keep the existing installation directory fixed during updates to preserve registered services safely.
- Remove ProjectDB server address, application name and access password from Setup; applications are registered later from Service Manager.
- Remove service command, environment and package implementation details from the Setup UI.
- Match Setup colors, spacing, typography, fields and buttons to the Add ProjectDB application window.
- Rename Cancel to Close and keep it disabled while setup is running.
- Fresh installation no longer creates a default ProjectDB application service.
- Update mode preserves registered applications and local app.so, updates shared binaries and WinSW service wrappers, then restarts services that were running before the update.
- Preserve the offline ProjectDB 3.4.0 and WinSW 2.12.0 payloads.
